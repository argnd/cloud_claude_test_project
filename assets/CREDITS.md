# Credits

## Graphics

All sprites in `assets/atlas.png` come from the tile export of
[Dungeon Crawl Stone Soup](https://github.com/crawl/tiles) (release Nov-2015),
dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No tile from that
project's list of tiles under unknown licence is used.

Some tiles were composited, recoloured or extended for Emberdeep (for example the
party and NPCs built from paper-doll layers, Ilsa's Pale form, the biome palettes,
shop signs, chests, the bookshelf and a few effects). `tools/build_atlas.py`
regenerates the atlas and records exactly which source tiles each sprite uses.
